1El tablero es una lista

Aunque en pantalla vemos una cuadrícula, es más cómodo guardar las casillas en un array plano, una detrás de otra. La casilla de la fila r y la columna c está en la posición r × columnas + c. Para hacer el camino inverso usamos la división entera y el resto.

const rows = 9, cols = 9;

// Una casilla = un objeto con cuatro datos
const cells = Array.from({ length: rows * cols }, () => ({
  mine: false,   // ¿hay mina?
  count: 0,      // cuántas minas tiene alrededor
  open: false,   // ¿está abierta?
  flag: false,   // ¿tiene bandera?
}));

// De fila y columna a índice, y vuelta
const index = r * cols + c;
const r = Math.floor(index / cols);
const c = index % cols;

Por qué así: con un solo índice por casilla, guardar, buscar y dibujar es mucho más sencillo que con un array de arrays. Cada botón del tablero lleva su índice en data-i.

2Las casillas vecinas

Casi todo en el Buscaminas depende de las ocho casillas que rodean a otra. Recorremos los desplazamientos de −1 a 1 en filas y columnas, saltamos la propia casilla y descartamos las que se salen del tablero. Por eso los bordes tienen 5 vecinas y las esquinas solo 3.

function neighbors(i) {
  const r = Math.floor(i / cols), c = i % cols;
  const result = [];
  for (let dr = -1; dr <= 1; dr++) {
    for (let dc = -1; dc <= 1; dc++) {
      if (dr === 0 && dc === 0) continue;     // la propia casilla no cuenta
      const nr = r + dr, nc = c + dc;
      // Solo las que están dentro del tablero
      if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) {
        result.push(nr * cols + nc);
      }
    }
  }
  return result;
}

3Colocar las minas

El truco para que nunca pierdas en la primera jugada: las minas se colocan después del primer clic, evitando esa casilla y sus vecinas. Para elegirlas al azar barajamos la lista de casillas libres con el algoritmo de Fisher–Yates, en el que cualquier orden es igual de probable, y nos quedamos con las primeras.

function placeMines(safeIndex) {
  // La casilla pulsada y sus vecinas nunca tienen mina
  const forbidden = new Set([safeIndex, ...neighbors(safeIndex)]);
  const candidates = [];
  for (let i = 0; i < cells.length; i++) {
    if (!forbidden.has(i)) candidates.push(i);
  }

  // Barajado Fisher–Yates: recorre de atrás hacia delante
  // e intercambia cada posición con otra al azar anterior
  for (let i = candidates.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [candidates[i], candidates[j]] = [candidates[j], candidates[i]];
  }

  // Las primeras de la lista barajada son las minas
  candidates.slice(0, totalMines).forEach((i) => (cells[i].mine = true));
}

4Calcular los números

Con las minas colocadas, cada casilla guarda cuántas tiene alrededor. Lo calculamos una sola vez al empezar, en lugar de repetirlo en cada clic. Fíjate cómo reutilizamos neighbors: una línea basta.

cells.forEach((cell, i) => {
  cell.count = neighbors(i).filter((n) => cells[n].mine).length;
});

5Abrir casillas en cadena

Cuando abres una casilla sin minas alrededor, sus vecinas se abren solas, y si alguna de ellas también es un 0, la cadena sigue. Es un recorrido de grafo conocido como flood fill. Lo hacemos con una pila: metemos la casilla pulsada, sacamos una, la abrimos y, si es un 0, metemos sus vecinas. Repetimos hasta vaciar la pila.

function openCell(i) {
  if (cells[i].open || cells[i].flag) return;
  if (cells[i].mine) return lose(i);

  const stack = [i];                // casillas pendientes de abrir
  while (stack.length) {
    const k = stack.pop();          // sacamos la última
    const cell = cells[k];
    if (cell.open || cell.flag) continue;
    cell.open = true;
    paint(k);                       // la dibujamos abierta
    // Si no tiene minas alrededor, sus vecinas también se abren
    if (cell.count === 0) stack.push(...neighbors(k));
  }
  checkWin();
}

¿Y por qué no recursión? Una función que se llama a sí misma también funciona, pero en un tablero grande puede encadenar cientos de llamadas y agotar la pila del navegador. Con un array como pila, el límite es la memoria.

6Clics, banderas y final de partida

En vez de poner un listener en cada una de las 81 casillas, ponemos uno solo en el tablero y miramos qué casilla se ha pulsado con closest. Es la delegación de eventos. El clic derecho dispara contextmenu, que usamos para la bandera. En el juego real, además, una pulsación larga de 400 ms pone bandera en el móvil.

// Un solo listener para todo el tablero (delegación de eventos)
board.addEventListener('click', (e) => {
  const cell = e.target.closest('.cell');
  if (cell) openCell(+cell.dataset.i);
});

// Clic derecho: bandera en lugar del menú del navegador
board.addEventListener('contextmenu', (e) => {
  const cell = e.target.closest('.cell');
  if (!cell) return;
  e.preventDefault();
  toggleFlag(+cell.dataset.i);
});

// Se gana cuando solo quedan tapadas las minas
function checkWin() {
  const opened = cells.filter((c) => c.open).length;
  if (opened === cells.length - totalMines) win();
}
