Cómo se juega

  • Destapa dos cartas por turno. Si muestran el mismo dibujo, se quedan descubiertas.
  • Si no coinciden, se vuelven a tapar después de un instante.
  • Completa todas las parejas con el menor número de intentos posible.
  • Con teclado: flechas para moverte y Enter o Espacio para voltear una carta.
